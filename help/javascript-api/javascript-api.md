# Javascript API

Marketo client-side JavaScript integrations provide lead tracking, forms, web personalization, and predictive content capabilities. You must have a Marketo account to use these capabilities.

Implementation typically involves adding embed code to your web property. You can also call the JavaScript functions exposed by the embed code to add functionality.

The embed code is unique to your Marketo instance because it contains an account identifier. In the Marketo user interface, go to the appropriate panel, copy the embed code to your clipboard, and paste it into your webpage.

## Lead Tracking (Munchkin)

Marketo's [Munchkin JavaScript tracking code](lead-tracking.md) generates leads from visits to your website. It also tracks visitors who have not provided personal information and creates anonymous leads that include the user's IP address and other information.

Set up Munchkin on the Munchkin page in the Admin area of Marketo.

## Forms 2.0

[Forms 2.0](forms-api-reference.md) lets marketers create web forms without programming knowledge. Forms can reside on Marketo landing pages or be embedded on any page of your website.

Use the Forms 2.0 JavaScript API to extend the core functionality of a Marketo web form.

## Web Personalization

[Marketo Web Personalization](web-personalization.md) helps you engage prospects on your website in real time based on who they are and what they do.

## Predictive Content

[Marketo Predictive Content](predictive-content.md) uses machine learning and predictive analytics to present relevant content to web visitors. Add text descriptions and images to your content, and embed multiple content recommendations on your website.
