# Self-service Flow Steps

Self-Service Flow Steps let an integrator deploy a web API as a Flow Step in Marketo Smart Campaigns.

A Flow Step Service can:

- Receive lead and related data.
- Process the data, including calling other web services.
- Write lead and activity data to Marketo through a callback.

For implementation details, see the [developer documentation on GitHub](https://github.com/adobe/Marketo-SSFS-Service-Provider-Interface).
